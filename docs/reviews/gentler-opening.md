# Gentler Kana introductions

The owner approved a four-new-question starting preset and a gentler opening. The first eight questions are reading あ, reading い, listening あ, listening い, then the same sequence for う and え. Every rolling window of four authored questions contains at most two new basic kana, including when a learner resumes partway through the sequence. Words and other exercises use the same allowance; this does not promise two new characters every day or a ten-minute upper limit. Reviews remain first.

Basic reading/listening questions use adjacent pairs in the existing script order. Each reverse has at least one intervening question after its reading exposure. Shared お／を and オ／ヲ listening waits for both forms. The already-readable ほん exercise moves into early katakana as consolidation between reading カ and its listening question, filling the gap while オ／ヲ remains delayed. It is introduced as a word there, not claimed as previously learned vocabulary. Rule, comparison and final decoding content remain unchanged.

The target stays gold, without an underline. Each figure draws only its target and previously introduced same-script kana within the existing three-row frame. The first figure contains only あ; the second contains あ and い. Every drawn pronunciation is covered with hideAll; future glyphs, readings and their regions are absent. Unused row dividers disappear. Figures are static authored snapshots: an older card keeps its earlier view during later reviews.

The inventory remains 290 questions in each language. All GUIDs, native card/note/book IDs, existing model/field/template IDs, answers, recordings and font sizes are preserved. Table assets use -introduced- filenames to avoid collisions with the old -rows- figures. The 92 question PNGs and all other artwork remain byte-identical. Existing scheduling and learner options survive updates. A fresh gallery add receives the four-question preset; file imports need manual options, and an existing six-question setting is not reset automatically.
